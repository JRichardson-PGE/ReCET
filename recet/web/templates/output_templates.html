Output templates

An output template is a list of measure-level columns, in order. A run given one (New run, Outputs) writes only those columns, in that order, to its measure-level file; the Results tables, the portfolio summary and the key metrics still use every column. Every run also writes field_definitions, the definition and documentation link of each column in its file.
