    What does it check?

    The cells are checked every time the draft saves (the line above). Validate inputs adds the full check a run makes before pricing (files, programs, profiles, gas profiles, ACC years) on the saved tables, so you see what would stop a run or leave measures unpriced. Nothing is priced. The cells it flags are outlined in the table, red for a problem that stops the run and amber for a warning; hover a flagged cell to read why. Editing a flagged cell clears its outline until the next check. With CEDARS filing checks, the records CEDARS' upload would reject or warn on are outlined in amber too, under the rule's ID.
